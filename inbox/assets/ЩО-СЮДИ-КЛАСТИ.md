# assets — твої вставки для конкретного ролика

Картинки, скріншоти, короткі кліпи, які треба показати поверх кадру:
`.png`, `.jpg`, `.webp`, `.gif`, `.mp4`, `.mov`.

Це разові вставки «під цей ролик». Те, що плануєш використовувати
постійно, краще класти в `library/` — звідти воно підставлятиметься само
за ключовими словами.

Додавати зручніше через панель, у розділі вставок.
