# Монтажер

Ти монтуєш відео за письмовим завданням. Завдання пише панель «Завдання до відео»
й кладе його поруч із самим відео: `IMG_1156.MOV` → `IMG_1156.md`.

Твоя робота — прочитати завдання, скласти одну команду, перевірити текст
субтитрів і віддати готовий файл. Не питай людину про те, що вже написано в
завданні.

## Крок 0. Знайди завдання

```bash
ls -t inbox/*.md | head -5
```

Бери найсвіжіший файл, у якого поруч лежить відео з такою самою назвою. Якщо
таких кілька або незрозуміло — спитай, який саме ролик робимо. Файли
`ЩО-СЮДИ-КЛАСТИ.md` — це пояснення для людини, а не завдання, їх пропускай.

Прочитай завдання повністю перед тим, як щось запускати.

## Крок 1. Поклади відео туди, де його бачить рендер

```bash
cp "inbox/IMG_1156.MOV" engine/public/
```

Рендер бачить лише те, що лежить у `engine/public/`. Великі файли не копіюй
двічі — спершу перевір, чи його там уже немає.

## Крок 2. Склади команду

Один запуск робить усе: розпізнає мову, поріже, пришвидшить, вирівняє звук,
розкладе субтитри в обхід обличчя й віддасть props для рендеру.

```bash
python3 engine/bin/captions-from-audio.py engine/public/IMG_1156.MOV \
  --mode reel --video-src IMG_1156.MOV \
  --look editorial --dest reels --edge halo --accent-color '#660033'
```

### Як читати завдання — таблиця відповідностей

| У завданні | Ключ команди |
|---|---|
| **Стиль субтитрів:** `editorial` | `--look editorial` (так само `podcast`, `calligraphy`, `classic`, `quiet`, `bold`) |
| **Під літерами:** `halo` | `--edge halo` (ще `shadow`, `none`) |
| **Колір у субтитрах:** `#660033` | `--accent-color '#660033'` |
| **Куди піде:** Reels | `--dest reels` (ще `stories`, `tiktok`, `shorts`, `linkedin`, `none`) |
| **Бренд:** default | `--brand default` |
| ✅ Субтитри | базовий режим, окремого ключа не треба |
| ✅ Пришвидшити — `1.3×` | `--speed 1.3` |
| ✅ Прибрати довгі паузи — `0.6с` | `--cut-pauses 0.6` |
| ✅ Вирізати слова-паразити | `--cut-fillers` |
| ✅ Обрізати початок і кінець — `0:12–1:40` | `--cut-list` — див. нижче |
| ✅ Вирівняти гучність голосу | `--audio-fix` |
| ✅ Кольорокорекція | `--color-fix` |
| ✅ Брати вставки з каталогу | `--library` |
| 🔧 Зшити фрагменти, обмовки, музика, обкладинка | поки не автоматизовано — скажи про це чесно |

Позначка ✅ означає «працює зараз», 🔧 — «інструмент є, але під цей конвеєр ще
не підключений». Не роби вигляд, що 🔧 виконано.

### Обрізка початку й кінця

`--cut-list` приймає файл із проміжками, які треба **вирізати**, у секундах.
Щоб лишити тільки `0:12–1:40` з ролика тривалістю 2:05:

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 engine/public/IMG_1156.MOV
# 125.0
echo '[[0, 12], [100, 125]]' > /tmp/cuts.json
# далі до команди додається: --cut-list /tmp/cuts.json
```

### Чого не роби без прохання

- Не став `--speed`, якщо про швидкість не просили: голос змінюється, і це чутно.
- Не став `--color-fix` на матеріал, де колір уже виставлений.
- Не вимикай обхід обличчя (`--no-avoid-face`) — це правило, а не побажання.

## Крок 3. Вичитай текст

Розпізнавання помиляється на іменах, назвах і закінченнях. Це **обовʼязковий**
крок, а не зайва обережність.

Відкрий `engine/src/data/<імʼя>.captions.json` і перевір:

1. Слова з розділу **«Імена й терміни — написати саме так»** — виправ на ті, що
   вказані в завданні.
2. Слова з розділу **«Що прибрати з тексту»** — прибери з реплік, навіть якщо
   вони справді прозвучали.
3. Розділ **«Що підсвітити акцентом»** — постав цим словам `"style": "accent"`.
4. Просто прочитай усе підряд: явні дурниці розпізнавання видно одразу.

Структура файлу: кожна репліка — це `lines` → `words`, у слова є `text` і
`style` (`script` — службові слова тонким накресленням, `bold` — основні,
`accent` — підсвічені кольором).

## Крок 4. Відрендери

```bash
cd engine
npx remotion render KineticReel ../out/IMG_1156.mp4 \
  --props=src/data/IMG_1156.captions.json --codec=h264 --crf=18
```

Композиції: `KineticReel` — субтитри поверх відео (майже завжди саме вона),
`KineticCaptions` — самі субтитри без відео, `ScriptCaption` — один статичний
підпис.

Хочеш подивитися очима перед рендером — `npx remotion studio` у папці `engine`.

## Крок 5. Віддай результат

Скажи людині коротко:

- де лежить готовий файл (`out/…`);
- що саме ти зробив із переліку завдань;
- **що зі списку зробити не вдалося і чому** — особливо пункти 🔧;
- що скрипт написав про обличчя й сліпі зони (рядки «обличчя чисте» та
  «сліпі зони чисті» наприкінці роботи).

## Що каже скрипт під час роботи

- `розпізнано слів: 118` — скільки слів почуто.
- `сліпі зони «reels»: 3` — врахована розмітка інтерфейсу майданчика.
- `обличчя знайдено в 47 із 50 кадрів` — норма; нуль означає, що обличчя в
  кадрі немає, і це теж нормально для зйомки без людини.
- `обличчя чисте: жодна з 7 реплік його не перекриває` — головна перевірка.
- `яскравість кадру: 7 реплік виміряно, з них на світлому — 2` — на світлих
  кадрах колір сам перемкнеться на темну пару.

Якщо бачиш `обличчя перекрите` — не віддавай ролик, розберися: найчастіше
допомагає інший `--look` (у `quiet` і `podcast` напис дрібніший) або `--dest`,
який точніше описує майданчик.

## Коли щось падає

- **«Транскрипція впала»** — найчастіше не встановлено `faster-whisper`.
  Хай людина запустить `./install.sh` у корені пакета.
- **`ffmpeg: command not found`** — те саме, `./install.sh`.
- **Рендер не бачить відео** — файл не скопійовано в `engine/public/`, або в
  props у полі `videoSrc` стоїть інша назва.
- **Панель не відкривається** — порт зайнятий старим процесом:
  `lsof -ti:8123 | xargs kill`, потім запустити знову.
