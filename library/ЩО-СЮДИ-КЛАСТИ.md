# library — постійна бібліотека вставок

Те, що ти показуєш регулярно: логотипи, іконки, графіки, підписи, короткі
перебивки. На відміну від `inbox/assets/`, файли звідси підставляються
**самі** — коли в записі звучить потрібне слово.

Як це працює: поруч лежить `catalog.json`, де кожному файлу задані ключові
слова. Слово пишеться **коренем, без закінчення** — українська змінює хвіст,
а не початок. Корінь `фінанс` зловить і «фінанси», і «фінансовими».

```json
{
  "grafik-zrostannya.png": {"keywords": ["зроста", "графік", "динамік"]},
  "logo.svg": {"keywords": ["бренд", "логотип"]}
}
```

За замовчуванням в одному ролику зʼявиться не більше пʼяти вставок і не
частіше, ніж раз на шість секунд — щоб кадр не перетворився на ярмарок.

Порожня папка — нормально. Бібліотека наростає сама собою, коли починаєш
працювати.
