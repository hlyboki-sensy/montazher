# Монтажер Hlyboki Sensy

Знімаєш відео на телефон — отримуєш готовий ролик із субтитрами, які ніколи не
сідають на обличчя. Монтує Claude Code на твоєму компʼютері: нічого не
завантажується в чужі сервіси, ключі й підписки не потрібні.

*[English below](README.en.md)*

---

## Що він уміє

**Субтитри, які поважають кадр.** Скрипт знаходить обличчя в кожній репліці й
розкладає текст так, щоб він ніколи не перекривав лице. Заразом обходить сліпі
зони майданчика — колонку іконок у Reels, підпис і музику знизу, таймлайн
сторіс.

**Шість характерів субтитрів.** Форма й таймінги однакові, різниться
типографіка:

| Стиль | Вигляд | Коли брати |
|---|---|---|
| `editorial` | щіточний рукопис + важкий капс + кольоровий акцент | типовий вибір |
| `podcast` | дрібне біле, а раз на кілька секунд ключова фраза виходить великою | інтервʼю, розмова, довше за хвилину |
| `calligraphy` | уся репліка велика: класична каліграфія + білий капс | повільна розмова, де текст — частина картинки |
| `classic` | дідонівський серіф: курсив на службових словах, капс на решті | стримано й друковано |
| `quiet` | одне слово в кадрі, біле, малими літерами | коли увага має лишатися на обличчі |
| `bold` | усе білим капсом, ключове слово кольором | коли головне — швидко прочитати |

**Колір, який сам себе рятує.** Задаєш один акцентний колір. Скрипт міряє
яскравість кадру саме там, де стоятиме напис, і на темних кадрах бере
освітлену пару цього ж кольору, а на світлих — темну. Один і той самий колір
не може читатися і на снігу, і на нічному кадрі.

**Чистка запису.** Обрізка початку й кінця, вирізання довгих пауз і слів-паразитів,
пришвидшення без спотворення голосу, вирівнювання гучності, делікатна
кольорокорекція.

**Панель замість команд.** Іконка на робочому столі відкриває форму: додати
відео, обрати стиль, поставити галочки — і сказати Клоду, що завдання готове.

## Що потрібно

- Mac (пошук обличчя спирається на вбудований у macOS Vision)
- [Claude Code](https://claude.com/claude-code)
- Python 3.10+ і Node.js 18+ — якщо чогось немає, інсталятор скаже, звідки взяти

## Встановлення

```bash
git clone https://github.com/hlyboki-sensy/montazher.git
cd montazher
./install.sh
```

Перший запуск качає рушій рендеру й модель розпізнавання — це кілька хвилин.
Далі все працює миттєво й локально.

## Як монтувати

1. Кинь відео в `inbox/` — або натисни «Додати відео» просто в панелі.
2. Відкрий на робочому столі **«Завдання до відео»**, заповни форму, збережи.
3. Відкрий цю папку в Claude Code і скажи: **«завдання готове»**.

Далі Клод читає завдання, розпізнає мову, розкладає субтитри, чистить звук і
кладе готовий файл у `out/`. Поруч лягає текстовий файл з усіма репліками й
таймкодами — розпізнавання помиляється на іменах, і це найшвидший спосіб
вичитати текст. Виправив у ньому слово, сказав Клоду — він перезбере ролик.
Наприкінці Клод відкриває теку, шукати нічого не треба.

Хочеш обійтися без панелі — усе те саме робиться однією командою:

```bash
python3 engine/bin/captions-from-audio.py inbox/reel.mp4 \
  --mode reel --video-src reel.mp4 --look editorial --dest reels --accent-color '#660033'

cd engine && npx remotion render KineticReel ../out/reel.mp4 \
  --props=src/data/reel.captions.json --codec=h264 --crf=18
```

## Свій вигляд

Пакет приходить із нейтральним брендом: темне тло, світлий текст, сливовий
акцент `#660033`. Щоб зробити свій — скопіюй `engine/src/brands/default.ts`,
поміняй кольори й шрифти, додай у `engine/src/brands/index.ts`. Він одразу
зʼявиться у випадайці кожної композиції.

Колір субтитрів задається окремо, ключем `--accent-color` або кружечком у
панелі. Світлу пару для темних кадрів система порахує сама.

## Чого він поки не вміє

Чесно, щоб не було несподіванок: склейка кількох фрагментів із переходами,
вирізання обмовок і перезапусків фрази, підкладання музики, обкладинка,
автоматичний пошук вставок в інтернеті. У панелі такі пункти позначені 🔧 —
галочку поставити можна, але Клод скаже, що це поки робиться руками.

## Що всередині

```
montazher/
├── inbox/          сюди кладеш свої записи + завдання до них
│   └── assets/     разові вставки під конкретний ролик
├── library/        постійна бібліотека вставок + catalog.json
├── engine/
│   ├── bin/        розпізнавання, розкладка, різи, обличчя, яскравість
│   ├── src/        Remotion-композиції та бренди
│   └── public/     відео, яке бачить рендер
├── panel/          панель «Завдання до відео»
└── out/            готові ролики
```

## На чому це стоїть

Монтажер не переписував з нуля те, що вже добре зроблено іншими. Дякую:

- [Remotion](https://www.remotion.dev) — рендер відео з React-коду.
  **Увага: у Remotion власна ліцензія.** Для приватних осіб і малих команд
  безкоштовно, компаніям від певного розміру потрібна платна —
  [умови тут](https://www.remotion.dev/license).
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) — локальне
  розпізнавання мови з часом кожного слова (MIT).
- [OpenMontage](https://github.com/openmontage/openmontage) — агентна
  відеостудія, з якої почалася ідея конвеєра (AGPL-3.0; її код у цьому пакеті
  не використовується).
- [FFmpeg](https://ffmpeg.org) — усе, що стосується самого відео.
- Шрифти з [Google Fonts](https://fonts.google.com) під Open Font License:
  Montserrat, Inter, Playfair Display, Great Vibes, Comforter Brush.
